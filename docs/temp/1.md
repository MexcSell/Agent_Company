5. Important distinction: subscription vs API billing
A monthly subscription does not necessarily mean unlimited AI usage.

For example:

A ChatGPT subscription provides access to the ChatGPT product according to its plan limits.

Claude Code subscriptions provide access according to the applicable plan and usage limits.

API billing generally charges based on consumption.

A cloud hosting subscription may include a defined amount of CPU, memory, bandwidth, or storage.

A subscription for using an AI model through its website is not automatically permission to use that subscription as an API for your own agents. Your agent architecture must use a supported integration and billing method.

4. Example: connect DeepSeek to your Node.js agent
DeepSeek provides an OpenAI-compatible API interface. The following is a minimal Node.js example.

Install the SDK:

npm install openai

Create a file named agent.js:


import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com"
});

async function runAgent(task) {
  const response = await client.chat.completions.create({
    model: "deepseek-flash",
    messages: [
      {
        role: "system",
        content: "You are a software development agent."
      },
      {
        role: "user",
        content: task
      }
    ]
  });

  return response.choices[0].message.content;
}

const result = await runAgent(
  "Analyze this task and propose an implementation plan."
);

console.log(result);
