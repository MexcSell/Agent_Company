---
name: superpowers
description: Structured brainstorming, planning and TDD workflows.
---

1. Brainstorm: state the problem and 2-3 approaches with their trade-offs; pick one and say why.
2. Plan: small steps, each with the file it touches and how it is verified.
3. Implement test-first: a failing test, the smallest change that passes, then refactor.
4. Verify: run the checks; report the evidence, not an impression.
