---
name: context7
description: Up-to-date library documentation through the Context7 MCP server.
---

- Before using a library API you are not sure of, read its current docs with the context7 tools when they are granted (resolve the library id, then fetch the topic).
- Without the tools, read the installed package's source or docstrings instead of guessing.
- Prefer the version pinned in the project's lock file over the latest docs.
