---
name: feature-dev
description: Guided feature development: explore, design, implement, review.
---

1. Explore: find the code the feature touches and the conventions around it (naming, errors, tests).
2. Design: the interface, the data, the failure cases; write it down before coding.
3. Implement in the existing style, with tests for the new behaviour and its edge cases.
4. Review the result against the design and the acceptance conditions; fix the gaps.
